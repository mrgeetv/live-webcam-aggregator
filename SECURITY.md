# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/mrgeetv/live-webcam-aggregator/security/advisories/new),
not in a public issue or pull request. The report stays visible only to you and the
maintainers until a fix is published.

## Supported versions

Only the latest release gets security fixes. The `:latest` and current major image
tags (see the README's *Quick start*) are rebuilt when a fix ships, and daily when a
base image is patched.
